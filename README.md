# KiliKili Flutter MVP

KiliKili is a social-media-style Flutter MVP with:
- Home feed
- Stories UI
- Reels UI
- Search
- Create menu
- Profile
- Chat
- Notifications
- Shop
- Creator Studio
- USD wallet/payout UI
- Settings

## Run

1. Install Flutter SDK and Android Studio.
2. Create/open this project.
3. Run:

flutter pub get
flutter run

For an APK:

flutter build apk --release

For Google Play:

flutter build appbundle --release

## Important

This is an MVP UI/prototype. It does not yet include:
- real user authentication
- cloud database
- real video uploads
- real chat backend
- real advertising
- real creator earnings calculation
- real bank/PayPal payouts
- production moderation
- payment processing

Those should be connected through a secure backend before release.
